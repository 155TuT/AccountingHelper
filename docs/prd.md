# AccountingHelper 产品需求文档

依据：[现场编程作业要求](task-requirement.md)。

## 一、产品定位

AccountingHelper 是一个面向个人日常使用的纯前端记账 Web 应用，帮助用户记录收入与支出、回看近期账目，并按条件汇总收支。

核心流程：**打开或新建账本 → 记一笔 → 查看记录 → 筛选统计**。例如，用户记录午餐支出后，可以查看最近账目，再统计本周的饮食支出。

## 二、功能需求

| 功能     | 具体要求                                                                                                     | 优先级 |
| -------- | ------------------------------------------------------------------------------------------------------------ | ------ |
| 基础记账 | 选择收入或支出，填写日期、金额、类别和备注；保存成功后更新记录列表与统计结果                                 | 必须   |
| 全局设置 | 侧栏底部右侧打开浮动设置页，调整展示币种、六套主题色、深浅模式和默认保存目录；保存与关闭按钮沿用新建账目样式 | 必须   |
| 币种切换 | 在全局设置和金额输入中选择六种币种；统计、表格与图表按参考值换算，文件保留原币金额                           | 必须   |
| 类别管理 | 支持浏览器本地类别新增、重命名、删除，保留历史账目的类别并可筛选                                             | 必须   |
| 本地保存 | 使用本地 `.jsonl` 文件保存账目；用户打开已有账本或新建账本，新增记录后写回文件                               | 必须   |
| 最近记录 | 默认展示最近 10 笔，按记账日期倒序排列，同日按录入时间倒序；展示类型、日期、金额、类别和备注                 | 必须   |
| 收支统计 | 支持按日期区间、类别和金额区间筛选，分别显示匹配账目的总收入、总支出；默认统计全部账目                       | 必须   |
| 图表展示 | 收支走势支持柱状图与折线图切换；分类收入、分类支出支持环形图与条形图，展示金额、占比和笔数；各区域随筛选更新 | 可选   |

界面左侧为 VSCode 风格文件树，管理多个账本并列出账目；主内容区显示账目表格与收支统计，点击文件树账目会切到对应表格页并高亮。顶部左侧显示当前账本名，保存状态紧随其后。右下角“+”打开无蒙层的浮动卡片，卡片右下角与按钮重合；卡片标题为居中的“新建账目”，左上角主色圆形白色“✓”保存，右上角红色“×”取消。收入与支出使用清楚的文字标识；空账本提示添加第一笔，保存结果和输入错误在操作位置反馈。

新建账目中的日期、类别和币种面板在卡片左侧展开，同一时刻显示一个，切换控件时直接替换。选择后关闭对应面板；Esc 优先关闭当前面板并保留表单。筛选面板中的起止日期和类别同样互斥。全局设置使用带遮罩的浮动页，侧栏底部左侧为深浅色按钮、右侧为设置按钮；设置页保存或关闭前不改变当前主题与币种。

文件树账本行在悬停或键盘聚焦时显示保存、新建账目和关闭按钮。“新建账目”先选中所在账本，再打开与右下角“+”共用的浮动卡片；保存期间或浏览器不支持文件读写时禁用入口。顶部保留“另存为”。侧栏品牌区与工作区、工作区与底部设置区使用相同的主题边框分隔，适配深浅色。

页面品牌图标和浏览器标签页图标随当前深浅模式同步切换，包括系统初始主题、侧栏按钮和全局设置保存。

右上角文件操作区按“打开 / 保存 / 另存为”排列，使用统一按钮样式。打开支持批量选择账本，成功后切换至新打开的账本并重置筛选；保存写回当前文件，首次保存时选择位置；另存为选择目标文件。操作期间三个按钮均禁用，取消或失败时保留原账本状态。

筛选类别按一级收入、支出分组，二级类别可跨组多选。点击一级类别全选该组，再点取消；只选择部分二级类别时，一级类别显示部分选中。再次点击二级类别取消选择，菜单保持打开，点击“应用筛选”后生效。

## 三、技术选型

| 层次     | 选型与用途                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 前端     | React + TypeScript，组织页面组件、交互状态与账目类型                                                                                 |
| 构建     | Vite，提供本地开发服务并生成静态部署产物                                                                                             |
| UI       | [shadcn/ui](https://ui.shadcn.com/docs/installation/vite) + Tailwind CSS，按需引入 Button、Input、Select、Card、Table 等组件         |
| 存储格式 | [JSONL](https://jsonlines.org/)，使用 UTF-8 编码，每行一个账目 JSON 对象，行末使用换行符                                             |
| 文件读写 | [File System Access API](https://developer.chrome.com/docs/capabilities/web-apis/file-system-access)，通过用户选择和授权读写本地账本 |
| 类别存储 | 浏览器 `localStorage`，保存当前客户端维护的收支类别目录                                                                              |

解析、校验、筛选和统计均在浏览器内完成。运行与演示采用支持文件选择 API 的桌面版 Chrome / Edge，通过 localhost 或 HTTPS 访问；页面检测文件读写能力，并在需要时提示切换浏览器。

## 四、数据与计算规则

- **账目字段：** 类型、日期、金额、类别为必填项，备注可选；每笔账目保存唯一标识和录入时间。
- **日期：** 默认当天，支持选择其他日期，统一保存为 `YYYY-MM-DD`。
- **金额：** 采用所选币种，输入正数，最多两位小数；以整数分存储和计算，展示保留两位小数。
- **币种：** CNY、USD、EUR、JPY、HKD、GBP，100 分 = 1 单位。旧账目缺少币种字段时按人民币读取。汇率为内置演示参考值；统计、筛选和图表统一换算，文件树保留原币。展示溢出时提示并保留原始记录。
- **显示偏好：** 全局币种、主题色、深浅模式和默认保存目录只在当前页面会话中保留。默认保存目录通过浏览器目录选择器授权，并作为首次保存和另存为对话框的起始目录；选择目录后点击保存才生效，清除后恢复浏览器默认位置。
- **类别：** 首次使用提供常用收支类别，之后由用户在当前浏览器新增、重命名或删除。类别名称为 1–20 个字符且不可重名，每种收支至少保留一个类别；重命名或删除不修改历史账目。
- **筛选：** 日期和金额区间均包含边界，留空表示该端不限。所选类别之间取并集，再与日期和金额条件取交集；未选类别表示不限，历史同名类别按收支类型区分。起点大于终点时提示修正。
- **统计：** 收入与支出分别累加，金额筛选针对单笔账目；筛选无结果时，两项合计均显示 `0.00`。
- **打开：** 用户可一次选择多个文件，逐行解析并校验字段，整批通过后载入；重复打开同一文件刷新原会话；读取异常时提示错误行号或原因，保留当前账本与原文件。刷新或重新打开页面后，用户重新选择账本。
- **保存：** 新建账本先创建空会话，首次保存或添加记录时选择文件位置；新增记录校验通过后，将完整账本序列化为 JSONL 写回。写入并关闭文件流成功后显示保存成功；失败时保留表单和已有数据，提示授权或重试。

单行记录示例：`amountCents` 表示金额分，`createdAt` 使用 ISO 8601 时间，`type` 取 `income` 或 `expense`。

```jsonl
{"id":"r001","type":"expense","date":"2026-11-07","amountCents":2550,"category":"饮食","note":"午餐","createdAt":"2026-11-07T14:00:00+08:00","currency":"CNY"}
```

## 五、验收标准

三笔基础验收数据位于 [test/fixtures/prd-ledger.jsonl](../test/fixtures/prd-ledger.jsonl)。生活化演示使用 [校园周账本](../examples/campus-week-2026-10-26.jsonl) 和 [城市月账本](../examples/city-month-2026-10.jsonl)，均为独立虚构案例，由使用者手动打开。

| 场景         | 通过条件                                                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 记录与持久化 | 新建账本，添加饮食支出 25.50 元、交通支出 2.00 元、工资收入 100.00 元；文件包含三行合法 JSON 对象，刷新页面并重新打开原文件后，三笔记录及各字段完整 |
| 查看最近账目 | 添加超过 10 笔记录后，列表按约定顺序展示最近 10 笔，收入与支出容易区分                                                                              |
| 核对统计     | 上述三笔账目的总收入为 100.00 元、总支出为 27.50 元；筛选“饮食”后总支出为 25.50 元，收入为 0.00 元                                                  |
| 组合筛选     | 日期、类别、金额条件单独及组合使用时，合计与匹配账目逐笔求和一致；边界值计入，空结果显示零                                                          |
| 多账本联调   | 切换账本、日期及账目时表格定位正确，重复打开去重，保存期间禁止切换或关闭，关闭仅移出工作区                                                          |
| 币种与类别   | 六种币种录入和换算，原币金额保存；本地类别增删改查跨刷新保留，历史类别仍可筛选                                                                      |
| 异常反馈     | 缺少必填项、金额为零或负数、超过两位小数、区间颠倒时提示修正；JSONL 行格式或字段错误时提示行号；授权取消或文件读写失败时保留已有数据                |
