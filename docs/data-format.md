# JSONL 账本格式

每个账本是 UTF-8 编码的 `.jsonl` 文件。每行包含一个 JSON 对象，写出时以 `\n` 分隔并保留末尾换行；读取兼容 LF 与 CRLF。空文件表示空账本。

<!-- prettier-ignore -->
```jsonl
{"id":"r001","type":"expense","date":"2026-11-07","amountCents":2550,"category":"饮食","note":"午餐","createdAt":"2026-11-07T14:00:00+08:00","currency":"CNY"}
```

| 字段          | 类型   | 约束                                                  |
| ------------- | ------ | ----------------------------------------------------- |
| `id`          | string | 非空，账本内唯一；新记录使用 UUID                     |
| `type`        | string | `income` 或 `expense`                                 |
| `date`        | string | 真实日期，`YYYY-MM-DD`，年份 1000–9999                |
| `amountCents` | number | 大于零的安全整数，单位为记账币种的分                  |
| `category`    | string | 非空类别文字，兼容自定义及历史类别                    |
| `note`        | string | 可为空字符串；换行按 JSON 字符串规则转义              |
| `createdAt`   | string | 带时区的 ISO 8601 录入时间                            |
| `currency`    | string | 记账币种，取 `CNY`、`USD`、`EUR`、`JPY`、`HKD`、`GBP` |

类别目录由当前浏览器维护，不写入账本；新增或重命名目录项限 1–20 个字符。读取历史账目时只要求类别为非空字符串，删除或改名不改写账目。当前版本检查所有字段，并对额外字段给出错误提示，便于发现格式不兼容。

## 币种

`currency` 记录这笔账目记账时使用的币种，与 `amountCents` 一起描述原始金额，例如 `"currency":"USD","amountCents":1000` 表示 10.00 美元。读取旧账本时，缺少 `currency` 的行按人民币 `CNY` 补齐；明确写为 `null`、未知代码或小写代码会报错。写入时统一写出币种字段，因此升级后的账本可以直接被同一版本读回。

切换展示币种不会改写文件内容：统计、表格和图表按 [币种与换算](../src/domain/currency/currencies.ts) 中的参考汇率把每笔金额折算到当前币种后展示，汇总、筛选和图表使用同一份折算结果；汇总与筛选只在页面内完成，保存时仍写回原始币种和原始金额。

## 金额

用户输入以当前币种单位计，最多两位小数。程序拆分整数和小数位并换算为分；例如 `25.50` 保存为 `2550`。`0`、负数、科学计数法及超过两位小数的输入会要求修正。筛选下界和上界可以为零。

六种币种统一使用 100 分 = 1 单位，包括日元。参考汇率为内置演示值，不联网更新。每笔换算四舍五入到目标币种的分后再汇总；文件树始终显示原币金额。

单笔金额和同一币种各自的收支合计均须处于 JavaScript 安全整数范围。超出范围时要求调整金额或拆分账本，保证计算精确。

## 读取与保存

读取时逐行解析并校验字段、唯一标识和每币种合计，合计溢出也报告行号。多选文件全部通过后才加入工作区；重复打开同一文件会刷新原会话，同名不同文件可以共存。格式错误、空白账目行或重复标识会指出行号。末尾换行作为行分隔符处理。

保存前核对文件与打开时的内容快照。发现外部修改时提示重新打开。完整账本写入成功并关闭文件流后，界面才确认保存；失败时保留原会话与输入。

同一账本按单窗口操作。账本移动、权限变化或写入占用会产生可重试的提示。另存为不能覆盖工作区中的另一本账本；选择当前文件仍会检查外部修改。需要复制账本时使用“另存为”，或在文件管理器中复制 `.jsonl` 文件。

## 示例

[acceptance.jsonl](../examples/acceptance.jsonl) 包含三笔验收记录：饮食支出 25.50 元、交通支出 2.00 元、工资收入 100.00 元。总支出为 27.50 元，总收入为 100.00 元，结余为 72.50 元。
