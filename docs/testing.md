# 验收与测试

## 自动化检查

```bash
npm test
npm run build
npm run format:check
git diff --check
```

| 模块命令                   | 覆盖行为                                                                         | 测试文件                                                                                      |
| -------------------------- | -------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `npm run test:ledger`      | 金额精度、日期、筛选、排序、合计和图表口径                                       | `src/domain/ledger/ledger.test.ts`                                                            |
| `npm run test:currency`    | 六种币种、整数换算、四舍五入、溢出、原记录不变                                   | `src/domain/currency/currency.test.ts`                                                        |
| `npm run test:categories`  | 类别增删改、重名、最后一项保护、本地存储异常与恢复                               | `src/domain/ledger/categories.test.ts`、`src/infrastructure/storage/category-storage.test.ts` |
| `npm run test:storage`     | JSONL 往返、行号、打开与保存、取消、写入清理、快照冲突                           | `src/infrastructure/storage/storage.test.ts`、`test/robustness.test.ts`                       |
| `npm run test:workspace`   | 多账本同 ID 选择、批量打开回滚、句柄去重、串行保存、关闭失败、另存为保护         | `src/features/ledger/workspace.test.ts`                                                       |
| `npm run test:integration` | PRD 验收账、旧格式与自定义类别、混合币种保存、筛选单位换算、每币种合计和历史类别 | `test/acceptance.test.ts`、`test/integration.test.ts`                                         |
| `npm run test:ui`          | 空状态、原币明细、文本转义、自定义类别、分页、零金额占比、表单组合               | `src/features/entries/ui.test.tsx`                                                            |

存储与工作区测试使用模拟文件句柄；界面输出测试使用 React 服务端渲染，不等同于浏览器事件测试。原生文件选择、授权、键盘焦点和深浅色需要桌面验收。

## 持续集成

`.github/workflows/ci.yml` 在 push、pull_request 和手动触发时运行：

- Node.js 22.12 与 24 分别执行锁定依赖安装、格式检查和生产构建。
- Node.js 22.12 执行全部测试，检查最低支持版本兼容性。
- Node.js 24 按上述七个模块分别执行测试，失败会显示具体模块，其余模块继续运行。
- 同分支新任务取消旧任务。Pages 工作流仍执行完整测试和子路径构建后部署。

功能、字段或验收口径变化时，同步补充对应模块与联调用例。新增测试文件要归入一个模块命令，完整 `npm test` 仍覆盖所有测试文件。

## 桌面验收

使用桌面版 Chrome / Edge，通过 localhost 或 HTTPS 访问，窗口宽度至少为 1280px。

| 场景         | 操作                                         | 预期                                                             |
| ------------ | -------------------------------------------- | ---------------------------------------------------------------- |

| 首笔记账     | 打开浮动卡片，填写记录并选择保存位置         | 文件写入成功后才更新界面，取消文件选择保留输入                   |

| 多账本       | 批量打开、切换、点击日期及账目、关闭         | 当前账本与表格选择正确，关闭仅移出工作区                         |
