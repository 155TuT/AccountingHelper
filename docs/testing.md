## 桌面验收

使用桌面版 Chrome / Edge，通过开发服务或 HTTPS 访问，窗口宽度至少为 1280px。

| 场景       | 操作                                                                          | 预期                                            |
| ---------- | ----------------------------------------------------------------------------- | ----------------------------------------------- |
| 首次使用   | 打开页面，切换总览与全部账目                                                  | 工作台为空，统计为零，可直接填写第一笔账目      |
| 首笔记账   | 在空工作台填写记录并提交，选择保存位置                                        | 创建 JSONL 文件并保存第一笔记录；取消时保留输入 |
| 新建账本   | 选择保存位置，创建 `.jsonl` 文件                                              | 出现空账本，统计为零，提供新增入口              |
| 记账与重开 | 添加 25.50 元饮食支出、2.00 元交通支出、100.00 元工资收入，刷新后重新打开文件 | 字段完整；收入 100.00、支出 27.50、结余 72.50   |
| 验收文件   | 打开 `examples/acceptance.jsonl`                                              | 与三笔账目的预期一致                            |
| 筛选交集   | 同时选择日期、类别与金额；使边界恰好等于已有记录                              | 边界记录计入，各区域使用相同结果                |
| 无结果     | 选择没有记录的日期                                                            | 合计为零，图表与表格显示空状态                  |
| 非法输入   | 输入零、负数、三位小数或颠倒的区间                                            | 明确提示修正，已有记录保持完整                  |
| 文件错误   | 在副本第二行写入错误 JSON，然后尝试打开                                       | 提示第 2 行错误，原账本继续显示                 |
| 保存异常   | 取消文件选择，或在文件授权时选择拒绝                                          | 保留当前账本与表单，可重新操作                  |
| 外部修改   | 打开文件后在编辑器中修改文件，再新增账目                                      | 提示重新打开，保护外部修改                      |
| 深浅色     | 切换主题、打开筛选与日期弹层、刷新                                            | 文字和组件清楚；刷新回到空工作台与系统主题      |
| 键盘操作   | 用 Tab 切换控件、Enter 提交表单或按钮                                         | 焦点可见，常用流程可完成                        |

演示建议先新建空账本，完成三笔数据录入与筛选，再展示文件内容、刷新重开和主题切换。
