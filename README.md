# AccountingHelper

一个简洁的桌面个人记账本。使用 React + TypeScript + Vite 构建，界面基于 shadcn/ui，账目保存在用户选择的 JSONL 文件中。

本项目为 2026 秋福州大学软件工程现场编程作业

## 快速开始

推荐 Node.js 24 LTS，最低版本为 22.12。使用 npm 安装锁定的依赖：

```bash
npm ci
npm run dev
```

在桌面版 Chrome 或 Edge 中打开终端显示的地址，通常为 `http://127.0.0.1:5173`。界面按桌面使用设计，建议窗口宽度至少为 1280px。

## 使用

打开页面即可使用空工作台。点击右下角“+”打开“新建账目”卡片，填写后点击左上角“✓”保存，浏览器会让你选择账本保存位置；也可以先新建或打开已有账本。

1. 将鼠标移入左侧“工作区”显示新建和打开按钮（键盘 Tab 也可聚焦）。新建账本先在会话中创建；打开支持多选 `.jsonl` 文件。点击账本切换，点击日期筛选当天，点击账目定位主表格中的记录。
2. 在“新建账目”卡片中选择收支类型，点击金额左侧的币种入口可切换币种，再填写金额、类别和日期，按需添加备注。日期、类别和币种面板互斥，选择后收起；类别支持方向键与回车选择，Esc 关闭当前弹层。
3. 点击左上角“✓”。首次保存会选择文件位置，文件写入完成后，记录、统计和图表同步更新，浮动卡片关闭。保存失败时输入保留；右上角“×”或 Esc 取消，卡片没有背景蒙层。
4. 使用“筛选账目”组合日期、类别和金额条件。类别按收入、支出分组，支持整组选择、跨组多选和再次点击取消；应用后生效，未选类别表示不限。“全部账目”按每页 10 笔显示。
5. 总览依次显示走势、汇总卡片和分类分析。走势支持柱状图和平滑折线图，默认显示每日收入、支出和截至当天的累计结余；点击汇总卡片单独查看，再点恢复全部。累计范围沿用筛选结果，末日结余与汇总一致。分类环形图圆心距标题位置固定，类别列表向下延伸。
6. 在表单“管理类别”中新增、重命名或删除类别。类别目录保存在当前浏览器，历史账目的类别仍可筛选。
7. 文件树上的保存、新建账目和关闭按钮在悬停或键盘聚焦时显示。“新建账目”选中所在账本并复用右下角“+”的浮动卡片。右上角按“打开 / 保存 / 另存为”提供文件操作；关闭账本仅移出工作区。
8. 点击侧栏底部左侧按钮切换深浅色，点击右侧设置按钮打开全局设置，可调整币种、六套主题色、深浅模式和默认保存目录。点击“✓”后生效，关闭或点击遮罩放弃修改；默认目录用于首次保存和另存为，并仅在当前页面保留。刷新或重新打开页面后，通过“打开账本”重新选择文件。

文件读写通过浏览器的 File System Access API 完成，需要用户授权以及 localhost 或 HTTPS 环境。账目仅持久保存在所选 JSONL 文件中；页面会话结束后清空账目、筛选、币种和主题状态，下次打开从空工作台开始。仅类别目录通过 `localStorage` 跨刷新保留。

周、月虚构人民币案例分别位于 [校园一周](examples/campus-week-2026-10-26.jsonl)（39 笔）和 [城市生活一月](examples/city-month-2026-10.jsonl)（154 笔）；三笔 PRD 验收数据保存在 `test/fixtures/prd-ledger.jsonl`。

## 当前功能

- 多账本文件树、按日期筛选、账目表格定位与右下角浮动记账卡片。
- 本地类别增删改查；删除和重命名不改写历史记录。
- 收入与支出录入，金额以整数分保存和计算。
- JSONL 新建、打开、保存与另存为，错误提示精确到行。
- 全部账目分页、日期与金额区间及分组多选类别筛选。
- 总收入、总支出、结余和每日收支走势。分类支出与分类收入按金额降序展示各类别的金额、占比和笔数，随筛选更新。
- 金额输入框左侧提供币种入口，支持人民币、美元、欧元、日元、港币和英镑；切换后统计、表格与图表按参考汇率换算展示，文件树保留原币种，账本保留记账时的币种和金额。
- 侧栏底部提供全局设置入口，可切换展示币种、紫色/青色/蓝色/玫红/琥珀/绿色六套主题色、深浅模式，并选择默认保存目录。
- 深浅色主题，打开页面时跟随系统偏好，可在当前页面或全局设置中切换；侧栏品牌和浏览器标签页图标同步切换。
- 写入失败时保留表单；检测到文件被外部修改时提示重新打开。

汇率为内置演示参考值，不代表实时牌价。每笔换算四舍五入到分后汇总；换算或合计超出安全整数时显示错误并保留原币记录。六种币种统一采用 100 分 = 1 单位（含日元）。

## 项目结构

```text
src/
├── app/                     # 页面组装、桌面导航
├── components/              # 通用组件组合（日期选择器等）
│   └── ui/                  # shadcn 基础组件
├── domain/
│   ├── currency/            # 币种列表、参考汇率、换算与展示投影
│   └── ledger/              # 账目类型、校验、金额、筛选与统计
├── features/
│   ├── categories/          # 本地类别目录与管理弹层
│   ├── currency/            # 币种入口与当前展示币种
│   ├── entries/             # 记账表单、账目表格
│   ├── ledger/              # 账本会话、默认目录与操作状态
│   ├── settings/            # 全局币种、主题和目录设置
│   ├── statistics/          # 筛选、汇总卡片、图表
│   └── theme/               # 六套主题色与深浅模式
├── infrastructure/storage/ # 浏览器文件接口、JSONL 编解码
├── hooks/                   # shadcn 组件依赖的通用 Hook
├── lib/                     # 样式工具
└── styles/                  # 主题 token 和全局样式
docs/                        # 需求、架构、格式和验收说明
examples/                    # 周、月生活案例账本
```

业务规则放在 `domain`，文件接口放在 `infrastructure`，交互流程放在 `features`，页面通过 `app` 组装。模块测试与被测模块同目录，跨模块验收位于 `test/`。

## 常用命令

| 命令                   | 用途                          |
| ---------------------- | ----------------------------- |
| `npm run dev`          | 本地开发与热更新              |
| `npm run build`        | TypeScript 检查并生成 `dist/` |
| `npm run preview`      | 本地预览生产构建              |
| `npm run typecheck`    | 检查 TypeScript 类型          |
| `npm test`             | 执行业务规则、验收与存储测试  |
| `npm run test:watch`   | 开发时持续运行测试            |
| `npm run format`       | 使用 Prettier 统一格式        |
| `npm run format:check` | 检查格式                      |

CI 分别运行金额统计、币种、类别、文件存储、工作区、界面输出与跨模块测试，并在 Node.js 22.12 / 24 上检查格式和构建。最低版本运行完整测试，Node.js 24 按模块运行。对应本地命令见 [验收与测试](docs/testing.md)。

生产构建为静态资源。推送到 `main` 后，`.github/workflows/deploy-pages.yml` 检查代码并将 `dist/` 部署到 [GitHub Pages](https://155TuT.github.io/AccountingHelper/)，也可在 Actions 中手动触发。仓库 `Settings → Pages → Source` 需选择 `GitHub Actions`。

Pages 工作流按仓库名设置资源子路径。本地复现部署构建可运行 `npm run build -- --base=/AccountingHelper/`，再运行 `npm run preview -- --base=/AccountingHelper/`；部署到其他 HTTPS 静态站点时，按站点路径设置 `--base`。
